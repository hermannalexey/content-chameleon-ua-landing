# Content Chameleon — UA landing (preview)

Single-page landing for Ukrainian B2B companies entering Western markets via LinkedIn,
designed as a broadsheet newspaper in the Content Chameleon brand palette.

Static HTML/CSS/JS, no build step. Preview build: search-engine indexing is disabled
(`noindex` meta + `robots.txt`) until the site moves to its own domain.

Run locally: `python -m http.server` in this folder.
